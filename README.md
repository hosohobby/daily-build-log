# Daily Build Log 🚀

AI時代におけるエンジニアリング能力向上を目的として、
**「1日1個、小さく作る」** を継続的に記録するリポジトリです。

Claude Code / Codex などの AI コーディングエージェントを活用しながら、
実装・検証・学習内容を公開しています。

---

## 🎯 目的

* AIを活用した開発スキルを実践的に習得する
* 学習ではなく **Build Driven Learning（作りながら学ぶ）**
* 小さく作り、早く公開し、継続する
* 技術的思考と試行錯誤を可視化する

---

## 🧠 Philosophy（開発思想）

* 完璧より継続
* 小さく作って公開する
* AIは生成ツールではなく「共同開発者」
* 学習より実装
* Output First

---

## 📅 Daily Build ルール

* 原則 **1日1つ成果物を作成**
* 成果物は大小を問わない
* 必ず以下を残す

✅ 実装コード
✅ 学び
✅ 次の改善点
